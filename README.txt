FUNPLAY WORLD — BẢN MẪU 1
================================

Cấu trúc:
- index.html: trang chủ responsive, tìm kiếm, lọc thể loại, chuyển VI/EN.
- games/hanh-trinh/index.html: trò Hành Trình Phiêu Lưu đã có.
- games/tri-nho/index.html: trò Thử Thách Trí Nhớ.
- games/toan-nhanh/index.html: trò Toán Nhanh 60 giây.

Cách chạy thử:
1. Giải nén tệp ZIP.
2. Mở thư mục funplay_world.
3. Nhấp đúp index.html để mở bằng trình duyệt.
4. Chọn trò chơi để kiểm tra.

Cách đăng lên GitHub Pages:
1. Mở repository GitHub của bạn.
2. Tải toàn bộ NỘI DUNG trong thư mục funplay_world lên thư mục gốc của repository (root).
3. Bảo đảm tệp index.html nằm ở thư mục gốc, cùng cấp với thư mục games.
4. Commit thay đổi, chờ GitHub Pages cập nhật.
5. Mở URL GitHub Pages hiện có và kiểm tra các trò chơi.

Lưu ý:
- Đây là bản mẫu tĩnh, chưa có máy chủ hoặc bảng xếp hạng dùng chung.
- Điểm kỷ lục của game Trí Nhớ và Toán Nhanh được lưu trên trình duyệt của từng người chơi.
- Trước khi triển khai kiếm tiền, hãy kiểm tra điều khoản của nền tảng lưu trữ và nền tảng quảng cáo.
